    Hidden SSIDs are not shown in the list — type the exact name here.

    Rescan: Briefly pauses the setup AP to scan the area directly, then restarts the AP. Your phone reconnects to it automatically after a few seconds. Use this if your network isn't listed.

    Leave setup mode & reconnect (in the ☰ menu): Stops the setup AP and reconnects to a saved network — no reboot. The AP only reopens automatically if no saved network connects within 60 seconds.

    Shutdown (in the ☰ menu): Powers the device off cleanly. It stays off until its power is unplugged and plugged back in — there is no way to switch it on remotely.

    Marked ✓ (saved) and ★ (home network): ✓ means the device already knows this SSID (it is in the saved-networks list). That only means its credentials are stored — a recent connection attempt may still have failed. Reselect it and save again to update the password. ★ marks the home network, which is tried first.

    Saved networks — everything the device will try when it connects. ★ marks the home network: it is tried first, and the other saved networks are still used whenever it is out of range. Changes here are stored and take effect at the next connection (or after a reboot) — the device does not switch networks on its own.

      Tick it for the network the device should try first every time it connects; your other saved networks are used as fallback whenever it is not available. Leave it unchecked for a network you only want as a backup. It is pre-ticked only for the network that already is the home network.

      Save & connect: Saves the network and switches to it immediately — no reboot. The setup AP goes down for a moment while the device reconnects. If the switch fails, use "Save & reboot".

      Save & reboot: Saves the network and reboots the device so it connects reliably. The most robust choice, especially when "Save & connect" fails.

      Saving an already-saved network keeps its home-network star, so you can correct a password without losing the preference.
